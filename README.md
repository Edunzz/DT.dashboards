## English

A collection of **Dynatrace community contributions** by Jose Romero.
Here I share dashboards, workflows, and reusable resources ready to import
into your Dynatrace tenant.

> ⚠️ These resources are shared "as-is" as community contributions. They are not
> officially maintained or supported by Dynatrace. Review them before using in production.

### Contents

| Folder | Description |
|---|---|
| `mssql_server/` | Monitoring dashboard(s) for SQL Server. |
| `dynatrace/custom-documents-report-english/` | Dashboard + workflow to inventory and audit tenant documents (dashboards and notebooks) via Grail lookup table. |
| `dynatrace/custom-documents-report-spanish/` | Dashboard + workflow to inventory and audit tenant documents (dashboards and notebooks) via Grail lookup table. (Spanish version) |

### How to use
Each folder includes its own `README.md` with the import procedure,
considerations, and required permissions.

Author: Jose Romero — jose.romero@dynatrace.com
