# DT.dashboards

Repositorio de aportes a la **comunidad Dynatrace** por Jose Romero.
Aquí comparto dashboards, workflows y recursos reutilizables listos para importar
en tu tenant de Dynatrace.

> ⚠️ Estos recursos se comparten "as-is" como aporte comunitario. No son
> oficialmente mantenidos ni soportados por Dynatrace. Revísalos antes de usarlos
> en producción.

## Contenido

| Carpeta | Descripción |
|---|---|
| `mssql_server/` | Dashboard(s) de monitoreo para SQL Server. |
| `dynatrace/custom-documents-report/` | Dashboard + workflow para inventariar y auditar documentos (dashboards y notebooks) del tenant vía lookup table en Grail. |

## Cómo contribuir / usar
Cada carpeta incluye su propio `README.md` con el procedimiento de importación,
consideraciones y permisos requeridos.
